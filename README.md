## 🎯 How to Play

1. Open the application.
2. Click **Generate** to create a new Sudoku puzzle.
3. Fill in the empty cells while following Sudoku rules:

   * Each row must contain the numbers **1–9**.
   * Each column must contain the numbers **1–9**.
   * Each 3×3 sub-grid must contain the numbers **1–9**.
4. Complete the puzzle without repeating any number in a row, column, or sub-grid.
